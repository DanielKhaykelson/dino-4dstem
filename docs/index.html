What it does

Point it at a scan. Get a map of what's actually different.

DINO-4DSTEM learns the structure in your data by itself, then paints the distinct regions on your scan — and gives you the evidence behind every class.

Automatic

Groups every diffraction pattern into structurally distinct classes — phases, crystallinity, texture — with no labels and no hand-tuning.

Interpretable

See why each region is its own class: the average diffraction per class, attribution maps, and NMF / ACOM baselines to check the answer.

No code

A desktop app plus a plain-English assistant. Double-click to launch, or just ask: “load this file, then train.” It drives the pipeline for you.

Get started — two ways

Install in about 15 minutes. You only do it once.

Both ways need Miniconda (free) installed first. Pick the one that fits you.

Recommended · no git

Download & run

For everyone. No terminal, no commands.

  1. Install Miniconda (one time per computer).
  2. Download the ZIP and Extract it to a simple folder.
  3. Double-click install_1_environment.bat — builds the environment (slow, once).
  4. Double-click install_2_dino4dstem.bat — makes the Desktop icons.
  5. Launch DINO-4DSTEM from your Desktop. 🎉

Install with git

For getting updates with one command later.

  1. Install Miniconda and Git (one time).
  2. Clone the repository:
    # download the code
    git clone https://github.com/DanielKhaykelson/dino-4dstem
  3. Run the same two installers (or install.bat for both).
  4. Later, get the newest version anytime:
    # update to the latest
    git pull
    install_2_dino4dstem.bat

First time? The bundle includes GETTING_STARTED.docx — a picture-by-picture, click-by-click walkthrough. Running on an NVIDIA GPU is optional (see the install page).
